# Github: Branch
Branch adalah pembuatan jalur commit yang berbeda agar tidak mengganggu jalur utama (main branch). digunakan ketika : 
1. **Ingin membuat fitur experimental**
jadi misal ketika fitur experimental tidak bisa diterapkan atau tidak selesai dibuat kita bisa menghapus branch tersebut
2. **Bekerja dengan Tim**
jadi setiap individu bisa membuat branchnya sendiri

### 1. Cara membuat Branch
- klik main di bagian kiri
- ketik nama branch yang ingin di buat
- klik create branch ... from main

### 2. Menggabungkan dua branch
untuk menggabungkan kita bisa klik compare and pull request


**commit** adalah berpindah atau ke commit yang lain.
**pull request** adalah cara kita meminta untuk pemilik reponya atau main branchnya itu menarik perubahan kita.
**Merge** menggabungkan dua branch.
**Merge Conflict** adalah baris yang sama diubah 2 branch yang berbeda
