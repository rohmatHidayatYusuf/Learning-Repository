# Merge Conflict
Merge conflict adalah error yang terjadi ketika 2 branch mengerjakan baris yang sama

ketika merge conlict git bash akan otomatis membuka code editor default lalu akan muncul kedua isi filenya, kita bisa menggunakan salah satu file ataupun bisa menggabungkan isinya

## cara untuk kembali ke commit
1. `git checkout ec664`
1. buat branch baru `git branch test`
1. pindah ke branch yang baru dibuat `git checkout test`
