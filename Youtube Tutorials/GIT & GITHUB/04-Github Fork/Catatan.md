# Fork
Fork/forking adalah proses menduplikasi repository milik orang lain (beserta historynya). Dari sana kita bisa mengembangkan projek tanpa mengubah repository aslinya. Nantinya kita dapat mengusulkan perubahan (pull request) kepada pemilik repository agar dapat dipertimbangkan untuk digabungkan dengan repository yang sudah dikembangkan. Fork ini berbeda dengan clone, untuk clone itu menduplikasi repo ke komputer lokal kita, sedangkan fork ini menduplikasi repo ke repo github kita.

### 1. Melakukan Forking
1. Buka repo yang ingin di fork
1. klik fork di bagian kanan sejajar dengan nama repository
1. jika muncul form biarkan semuanya default lalu klik fork
