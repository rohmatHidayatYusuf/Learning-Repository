1.Membuat Repository

* untuk membuat repo kita bisa klik + di kanan atas lalu Ketika popup muncul klik new repository
* isikan Repository name
* isi Description (Opsional)
* pilih Repository itu untuk Public atau Private
* check the checkbox Initialize this repository with a README

README ini digunakan untuk menjelaskan Projek kita atau Repo kita itu melakukan apa

* lalu klik Create Repository



2\. Membuat File di Repository

* klik add file, lalu akan muncul dropdown
* di dropdown menu klik + create new file
* berikan nama filenya beserta exstensinya
* isi filenya
* kalua sudah selesai klik commit changes...
* isikan commit massage
* pilih Commit directly to the main branch
* klik Commit changes



3\. Mengedit file

* klik file yang ingin di edit
* klik logo pencil di bagian kanan
* ketikan perubahan
* klik commit changes...
* isikan commit massage
* pilih commit directly to the main branch
* klik commit changes



4\. Melihat apa saja yang sudah di ubah

* klik file yang ingin di lihat history perubahannya
* lalu klik history di bagian kanan



5\. cara melihat commit secara timeline visual

* klik Repository yang ingin dilihat secara visual
* klik insights dibagian kanan atas
* klik Network di bagian kiri
